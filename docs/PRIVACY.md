# 数据与隐私说明

## 仓库包含什么

项目源码、依赖锁文件、测试、应用图标和 Reader Lab 原创 EPUB 样书。公开准备副本不包含真实书籍、用户笔记、聊天记录、个人 Vault、数据库、登录配置、模型密钥、截图验收证据或开发者旧 Git 历史。

依赖来自公开的软件包源。公开第三方源码中的署名、链接和系统通用目录不属于用户账户信息。

## 应用运行时保存什么

桌面应用将书籍、位置、划线、笔记、讨论、草稿、确认结果和连接设置保存在用户本地应用数据中。连接设置可能包含用户选择的程序路径或 Vault 路径。这些运行时数据不能提交到公共仓库。

浏览器预览使用当前站点的 IndexedDB，数据与桌面独立。

## 哪些内容会进入模型

发起问答时，问题、阅读摘录及本次检索选取的笔记／已确认想法／Vault 摘录会进入已连接的 Codex 或 pi；这些程序可能将资料传给用户所选的模型服务。讨论历史的续谈也可能再次提供历史内容。Reader 会限制本次资料长度，但不意味着资料从不离开电脑。

助手问答不要求把密钥写进 Reader 仓库。用户自行配置连接程序的账户与服务，遵循相应服务的数据处理规则。

## Vault 行为

用户选择 Vault 后，Reader 本地检索 Markdown 文件并使用有限摘录。当前扫描受条目数、文件数量、时间、目录深度和大小限制，大型 Vault 可能只检索部分内容。修改、删除或断开后应以应用中的范围及状态反馈为准。

只有用户触发保存／确认和导出操作后才写入相应结果。导出文件含原文、笔记及回跳链接，分享前需自行检查。

## MCP 行为

MCP 是给外部工具访问 Reader 的可选入口，不是助手对话的前提。配置后，外部客户端可读取该 Reader 数据中的笔记等资料，并可能进一步传给它使用的模型。只向信任的客户端开放。

本机通道的权限检查不等于防御同一用户身份下的恶意程序。

## 报告问题

复现时使用原创样书、新建数据目录和测试 Vault。分享日志前移除正文、账户、个人路径和令牌。不要把密钥粘贴到公开 Issue；发现泄露时应立即撤销相应凭证，删除文件不能清除已公开的历史副本。
