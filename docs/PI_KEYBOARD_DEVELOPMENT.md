## 用户操作

- 在书架、阅读菜单或右侧助手打开「助手连接」，选择 Codex 或 pi agent，再点击「连接」。程序自动发现失败时可手动选择程序。
- pi 暂支持本机已安装的 1.0.0；沿用 pi 的默认模型和登录配置。连接状态展示模型，不读取或显示 API 密钥。未配置模型时提示先在 pi 中配置。
- 切换助手会断开原连接，记住选择和各自的程序路径；下次打开应用恢复选择，但不自动发送问题。
- 已绑定 Codex / pi 的对话保留原归属。切换后，原对话显示「请开启新对话使用当前助手」，发送暂时禁用，新对话使用当前助手。原历史与草稿保留。
- 阅读页按 ← 上一章、→ 下一章；↑ / ↓ 滚动当前章节，每次约可见高度的 12%，至少 48 像素，可按住连续滚动。章节边界不自动翻章。
- 点击 EPUB 正文后按键仍然有效；底部翻章按钮获焦时也可使用方向键；输入框、助手记录、其他按钮、设置菜单和弹窗保留自己的键盘行为。带修饰键的方向键保留系统行为；已有未保存笔记保护继续适用。

## 实现

### 连接与对话

`agent.rs` 统一管理 Codex / pi，并复用原有前端命令及事件名称。跨提供者使用独立代际，拒绝旧连接请求和迟到事件；同一时刻只允许一个请求。现有 Codex 0.159.2 / 0.160.0 协议代码保持原实现。

`pi.rs` 使用本机 pi CLI 的 RPC 模式、严格 LF JSONL 和带 ID 的命令响应。根据 1.0.0 安装包资料与上游文档实现 `get_state`、`new_session`、`switch_session`、`prompt`、`abort`。回答从文字增量展示，以最终消息更新内容，等待 `agent_settled` 才结束请求；不把提示已接受或 `agent_end` 当作完整答复。

- 启动时关闭通用工具、扩展、技能、提示模板、主题、上下文文件和项目文件发现；关闭启动联网检查及遥测。连接握手不包含书籍资料。
- 使用应用数据目录下的 `pi-workspace/` 和 `pi-sessions/`。只恢复 Reader 自有目录中的会话，路径检查拒绝外部文件；绑定采用 `pi:<sessionId>` 和 `pi-rpc/1.0.0`，不会把 Codex 线程传给 pi。
- 当前配置归属以 pi 提供者和模型区分；RPC 没有提供可核对的登录账号身份，不能据此声称验证了账号。模型或对话归属变化时要求新对话。
- 延续已有持久化输入快照、草稿、消息状态、严格 JSON 回答与逐字引文校验；pi 通过提示约定输出 JSON，完整输出仍在 Reader 内验证，失败不会成为可用引用。
- 保留 pi 自身重试和压缩偏好：相关 RPC 设置会写入全局设置，因此 Reader 不调用这些设置命令。总回答期限 120 秒；命令响应期限 15 秒；停止后 5 秒仍未结束则终止 Reader 启动的进程，要求重新连接。
- 标准错误持续排空，原始诊断和凭据不输出给前端。程序退出、协议异常和过长输出会结束当前请求并释放连接。

### 方向键

父页面与 EPUB iframe 共享按键处理。切章与原底部按钮使用同一入口，防止重复切章并延续编辑保护。上下键仅修改当前 EPUB 滚动容器，限制在当前章节范围。阅读动作不取消右侧持续回答。
