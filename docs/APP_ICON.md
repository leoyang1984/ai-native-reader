# 应用图标 / App icon

v0.1.1 使用深绿色底、米白书页和暖橙对话气泡，表达阅读与讨论。图像使用 Imagegen 辅助生成，以 Tauri 图标工具转换为 macOS ICNS；项目整体采用 GPL-3.0-only。图标源文件在 `src-tauri/icons/reader-v2.png`，macOS 资源在 `reader-v2.icns`。原图标保留。

The v0.1.1 icon combines an open book with a conversation bubble. The image was created with Imagegen and converted to macOS ICNS using the Tauri icon tool. Source assets are included under the project's GPL-3.0-only license. This update does not change reading or assistant behavior.
